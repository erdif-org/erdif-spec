    Invalid documents¶

    Each invalid example breaks exactly one rule. _comment explains which one, and _expect states the error a JSON Schema validator reports — the JSON Pointer of the failing value and the failing keyword. They are meant as test cases for importers.

    Example Broken rule Expected error
    missing-gps-fallback.jsonld geo is required on Location /realty/location — required
    price-without-amount.jsonld price-or-on-request /prices/0 — anyOf
    room-feature-on-realty.jsonld accessibility-level /realty/accessibility/0 — not
    land-with-rooms.jsonld land-has-no-rooms /realty/rooms — maxItems

    All examples are checked in CI by scripts/validate_examples.py: valid documents must pass the schema and expand as JSON-LD, invalid ones must fail with exactly the expected error and no other.
