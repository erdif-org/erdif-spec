    Location¶

    Description¶

    Location identifies where the property is. It combines three independent means of identification, described in detail in Geolocation:

    1. an INSPIRE identifier (InspireIdentifier) as the primary supranational reference,
    2. WGS 84 coordinates as a mandatory fallback, because an INSPIRE identifier may not exist yet (e.g. for new buildings),
    3. national identifiers (LocalIdentifier) and a postal address as supplementary information.

    Coordinates are often deliberately shifted to protect the exact address. The approximateCoordinates flag makes this explicit, so a consumer knows whether the point can be used for precise map display.

    Information about the surroundings is not part of the location; it is modelled separately as LocalArea.

    The entity is typed as schema:Place and erdif:Location.

    Properties¶

    Entity types: schema:Place + erdif:Location

    Location of the property combining three independent means of identification.

    Property Semantics Range Cardinality Description
    globalIdentifier erdif:globalIdentifier erdif:InspireIdentifier 0..1 Supranational INSPIRE spatial identifier.
    geo schema:geo schema:GeoCoordinates 1 WGS 84 coordinates. Mandatory fallback.
    approximateCoordinates erdif:approximateCoordinates xsd:boolean 1 Flag indicating whether coordinates are approximate.
    localIdentifiers erdif:localIdentifier erdif:LocalIdentifier 0..* National registry identifiers (e.g. RUIAN).
    address schema:address schema:PostalAddress 0..1 Postal address in local format.

    Validation rules¶

    • explicit-coordinate-precision — approximateCoordinates must always be stated explicitly, so that a missing value is never interpreted as a claim of exact position.

    Example¶

    "location": {
  "@type": ["Place", "erdif:Location"],
  "globalIdentifier": {
    "@type": "erdif:InspireIdentifier",
    "theme": "AD",
    "namespace": "CZ.CUZK.AD",
    "localId": "26777598"
  },
  "geo": { "@type": "GeoCoordinates", "latitude": 50.07553, "longitude": 14.43781 },
  "approximateCoordinates": false,
  "localIdentifiers": [ ... ],
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Korunní 810/104",
    "addressLocality": "Praha",
    "postalCode": "10100",
    "addressCountry": "CZ"
  }
}
