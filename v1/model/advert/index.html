    Advert¶

    Description¶

    Advert is the root entity of every ERDIF document and represents one offer of a property on the market. It carries the commercial part of the offer — transaction type, prices, marketing text, media and the contact — while the physical property is described separately in Realty.

    This split reflects the fact that one property can be offered repeatedly and in different ways over time (sold, later rented out), whereas its physical description stays the same.

    The marketing text (description) belongs to the advert, not to the property: it is written for one specific offer and changes with the transaction type.

    The entity is typed as schema:RealEstateListing, which makes the document understandable to search engines and generic schema.org consumers, and as erdif:Advert, which carries the ERDIF semantics.

    Validation rules¶

    • advert-id-vs-source-id — identifier identifies the advert in the system that issued this document; exportInformation.sourceAdvertId identifies it in the system where it originated. When the issuer is the originating system, both values are the same.
